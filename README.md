# Sistema Web para Minimercado - Mercadinho Express

## Funcionalidades do Sistema

### Visualização de Produtos
* Mostra 3 categorias diferentes de produtos (Hortifrúti, Padaria, Frios e Laticínios)
* Cada categoria exibe produtos com foto, descrição e preço
* Botões de "Adicionar ao Carrinho" funcionais

### Serviços Oferecidos
* Lista os serviços disponíveis no minimercado
* Cada serviço tem descrição e valor
* Sistema de agendamento para retirada ou entrega

### Navegação
* Menu principal no topo do site
* Links para todas as seções do sistema
* Carrossel na página inicial

### Estrutura do Site
* Cabeçalho com logo, login e cadastro
* Corpo com produtos e serviços
* Formulário de contato
* Rodapé com informações e links

### Recursos Adicionais
* Cadastro de clientes
* Login de usuários
* Agendamento de serviços
* Recursos de acessibilidade
* Carrinho de compras básico

## Tecnologias Utilizadas
* HTML5
* CSS3
* JavaScript
* Bootstrap 5
* Font Awesome
