# Sistema Web para Minimercado

## Funcionalidades do Sistema Web para Minimercado

### Visualização de Produtos
- Mostra 3 categorias diferentes de produtos
- Cada categoria exibe 2 produtos com foto, descrição e preço

### Serviços Oferecidos
- Lista os serviços disponíveis no minimercado
- Cada serviço tem descrição e valor

### Navegação
- Menu principal no topo do site
- Links para todas as páginas do sistema

### Estrutura do Site
- Cabeçalho com informações do minimercado e menu
- Corpo com produtos e serviços
- Rodapé com informações de contato e links

## Metas
1. Mostrar 3 categorias de produtos com imagens, descrições e preços
2. Listar os serviços oferecidos pelo minimercado com descrições e valores
3. Criar uma navegação fácil entre as páginas
4. Incluir informações de contato e sobre o minimercado
